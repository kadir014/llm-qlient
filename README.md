# llm-qlient
Playground for local Large Language Models with a Qt-based desktop user interface.



# Installation
Python 3.10+ and [uv](https://github.com/astral-sh/uv) is required. Clone the repository.
```sh
$ git clone https://github.com/kadir014/llm-qlient.git
$ cd llm-qlient
```
Run the client. `uv` should handle the environment.
```sh
$ uv run main
```
